# CubeSat Power Systems

An educational engineering project focused on modeling and analyzing electrical power systems for CubeSat-class spacecraft.

The project explores power budgeting, solar energy generation, battery behavior, and energy balance through numerical calculations and simulations.

## Objectives

- Estimate spacecraft subsystem power consumption.
- Model solar power generation under configurable conditions.
- Simulate battery state of charge.
- Analyze energy balance across different operating scenarios.
- Develop reusable, tested, and documented engineering tools.

## Technology Stack

- Python
- NumPy
- Matplotlib
- pytest

## Project Status

Under development. Initial models use illustrative parameters and simplified assumptions for educational and engineering analysis.
